# P1 常驻框架验证

已实现托盘、五组可配置全局热键、单实例命令转发、配置首次生成与热更新、自启开关、可选日志和崩溃转储。用户已授权连续开发 P1–P6，本报告是开发检查点，不作为发布或物理设备验收。

## 验证结果

- x64 / x86 Release 和 x64 ASan：P1 集成 **204 个用例、53,682 条断言**通过；项目源码 `/W4 /WX /analyze` 通过。
- 真实产品进程 E2E：两架构通过配置生成、实际热键注册、冲突恢复、无效字段和坏编码保留旧值、原子替换重载、第二进程命令转发、配置冲突拒绝、日志开关和清洁退出。测试隔离配置和注册表，不修改用户已有 Run 项。
- x64 空闲实测 **600.362 秒**：单核 CPU **0.0026026%**；专用工作集峰值 **3,719,170 字节，约 3.55 MiB**。满足 AC1-8；这是 P1 二进制数据，后续阶段须复测，不能外推完整应用资源占用。
- 改键、无效输入和原子替换的热更新实测约 **169–173 ms**。使用目录事件和一次性 150 ms 防抖，无常驻轮询。
- x64 / x86 子进程受控异常分别生成有效 AMD64 / x86 minidump，包含预期异常流及实际回退位置。普通安装过滤器不加载 dbghelp、不创建转储文件。
- 新增静态导入逐项核对 Microsoft Learn；白名单旁保存最低版本与原始 URL。静态审计仍不能替代 Win7 实机运行。

原始数据：[空闲](data/p1-idle-x64.json)、[x64 功能](data/p1-app-x64.json)、[x86 功能](data/p1-app-x86.json)。崩溃探针和日志在 `out/reports/p1-crash-*`；可用 `tests/e2e/CheckCrashDump.ps1` 复跑。

## 验收边界

热键测试先由另一个进程实际尝试注册验证占用和释放，再向被测进程自己的窗口发送 `WM_HOTKEY` 验证路由；不声称验证了人工键盘操作。托盘恢复测试仅向自有窗口发送 `TaskbarCreated`，没有终止 Explorer。首次启动提示、实际 Explorer 重启后的托盘表现、自启登录和第三方软件键盘竞争仍需交互环境清单确认。

严格 UTF-8 / UTF-16 BOM、非法行号、大小写键、未知项和首次 CREATE_NEW 写入均有单测。热重载保留上次有效项采用 AC1-4 的规则；已有配置从不自动改写。注册表测试使用独立测试路径。遇到损坏的真实自启值，托盘仍可打开，点击自启项可清除损坏值。

本阶段图像命令的提示为 AC1-2 要求的占位行为；P2/P3 开始替换为实际截图编辑流程。物理多屏、DPI 矩阵与旧系统验收沿用 P0 未完成项。
