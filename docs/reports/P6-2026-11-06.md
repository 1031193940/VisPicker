## 候选版最终回归

Release 的剪贴板、选区、文字、贴图、录制、生命周期与常驻检查均通过。x64 ASan 另跑了隔离剪贴板、选区、文字、短录制和真实产品退出流程，未报告 ASan 错误。两架构控制台/文件/管道/无控制台模式和受控崩溃转储探针通过。见 [x64 产品回归](data/p6-product-x64.json)、[x86 产品回归](data/p6-product-x86.json)、[ASan 生命周期](data/p6-lifecycle-asan.log)、[x64 转储](data/p6-crash-x64.json)、[x86 转储](data/p6-crash-x86.json)。

|---|---:|---:|
| 采集 / 丢 tick | 1795 / 5（0.278%） | 1800 / 0（0%） |
| WIC 合成帧 / 不一致 | 640 / 0 | 639 / 0 |
| GIF 时长 | 59.95 s | 59.96 s |
| 相对实际首帧至停止的误差 | 约 4.0 ms | 约 6.7 ms |

两次运行均 `not_eligible` 于物理显示性能。内存数值来自操作系统进程峰值，报告另列采样 private bytes 和理论管线上界。按同一远程会话复测 20 张 1080p 贴图，x64/x86 私有提交增量均约 295 MB，关闭后 GDI/USER 回到基线。见 [录制 x64](data/p6-recording-x64.json)、[录制 x86](data/p6-recording-x86.json)。

60 秒证据来自加入浸泡工具 Esc 选择项之前的构建，产品录制仍使用原有 Esc 交互。最终哈希重新通过两架构短录制、真实退出及静态导入检查。见 [最终 x64 录制](data/p6-recording-short-final-x64.json)、[最终 x86 录制](data/p6-recording-short-final-x86.json)、[最终 x64 生命周期](data/p6-lifecycle-x64.log)、[最终 x86 生命周期](data/p6-lifecycle-x86.log)。

第一次 x64 长测记录了 39.20–45.20 秒右下角 174×109 区域的外部内容，64 个合成帧不符预期。差分持续保存该区域直到下一帧恢复。将自有测试图样移到左上角，避开屏幕右下方，重跑仍按逐像素严格比较并取得零差异。留存 [失败报告](data/p6-recording-x64-first-failure.json)，不归档带外部内容的失败画面。

真实产品检查覆盖隐藏启动后的预览可见性、普通退出时参考图确认、重复 GIF 请求仅得到一个预览、会话结束无弹窗且保留 GIF、下次启动清理隔离环境中的过期录制。已目检 [选区](data/p6-overlay.png)、[模拟 192 DPI 预览](data/p6-preview-dpi192.png) 和 [录制条](data/p6-recordbar.png)。模拟 DPI 消息验证窗口布局，物理跨屏另列。

## P6 浸泡测试

当前工具覆盖生产捕获、屏幕锚定矩形/PNG、贴图创建关闭、1 秒录制与 WIC 回读；固定自有 256×144 被动图样，不使用用户剪贴板。每轮销毁临时编辑、贴图和录制对象后采样。全屏 Overlay、真实输入法、保存对话框和跨应用粘贴不在此测试内。

| 轮次 | 实际结果 | 可作何种证据 |
|---|---|---|
| 旧 schema 1 冒烟 | 60.945 秒；配置间隔 10 秒；9 轮（含 3 暖机）；最大起点间隔 10.015 秒；`passed=true` | [历史报告](../../out/reports/p6-soak-smoke/report.json)。只证明短生命周期跑通；其 GIF ±10% 和节奏宽容门槛已经收紧，不能作为修后工具验收 |
| schema 2 冒烟 | 60.783 s，9 轮；节奏通过，即时私有提交曾从 8302592 B 上升至 9412608 B，门禁失败 | [原始报告](data/p6-soak-smoke-schema2.json)。下一个采样回落，保留为瞬时峰值证据 |
| schema 3 冒烟 | 75.986 s，10 轮；空闲私有提交最多 +3.57%，句柄 194→197，GDI/USER 均保持 3，通过 | [原始报告](data/p6-soak-smoke-schema3.json)。即时样本仍保留，固定空闲采样的增长上限保持 `<5%` |
| 8 小时尝试 | 2026-11-06 15:27:40（UTC+8）启动，计划间隔 30 秒。339.717 秒后因自有图样像素不一致结束。3 轮暖机、11 轮测量，最长起点间隔 30.008 秒 | [启动记录](data/p6-soak-launch.json)、[完整失败数据](data/p6-soak-8h-attempt.json)。未到 10 分钟和 1 小时检查点，`eight_hour_passed=false` |

旧冒烟基线为第 3 轮：GDI=3，USER=3，handles=196，private bytes=8257536 B。后续最大 private bytes=8523776 B（约 +3.22%），最大 handles=197（约 +0.51%），GDI/USER 不变；`eight_hour_elapsed=false`、`eight_hour_passed=false`。远程会话字段为 true，物理性能资格为 false。

schema 3 沿用固定计划起点、250 ms 调度容差和 GIF 实际时间轴 10 ms 误差检查。每轮保存关闭后的即时样本与 2 秒空闲样本，暖机和后续使用相同空闲时点比较 `<5%`。浸泡禁用全局 Esc 注册。首次隐藏启动的图样捕获失败后，测试窗口改用明确的被动显示方式并移到左上角。见 [首次启动失败](data/p6-soak-hidden-first-failure.json)。

长测尝试中，GDI 和 USER 均保持 3，句柄基线 198、峰值 201。空闲私有提交从 8605696 B 上升到 9396224 B（+9.19%），资源检查失败。专用工作集最大增幅约 2.85%。这些样本不足以区分持续泄漏与运行时缓存变化。像素不一致的原因未能确认。当前远程会话配置了 900 秒不活动锁定，正式长测需要可持续保持桌面的测试会话。
