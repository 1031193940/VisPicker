## 本版更新

- **文字对齐与虚线边界**。文字输入框新增左对齐、居中对齐、右对齐（默认居中）以及顶端对齐、垂直居中（默认垂直居中），编辑过程中或选中已有文字标注均可实时切换；输入文字时显示简洁的主题色虚线边界，并彻底修复插入/删除文字与组合输入时的残影问题。
- **Ctrl 复用与吸附上一次截图区域**。触发截图、贴图或 GIF 进入选区阶段后，按住 `Ctrl` 键即可用虚线高亮显示上一次完成的截图区域，单击或按 `Enter` 直接吸附框选；按住 `Ctrl` 拖拽或调整选区时还会自动磁吸对齐上次区域边界。
- **稳定性与细节修复**。
  - 修复带点号文件名（如 `release-v1.2.3`）保存时自动补全扩展名及覆盖确认逻辑，保存异常时保留当前选区；托盘与贴图右键菜单加入模态重入保护。
  - 优化选区重绘与遮罩性能，支持在未选中的马赛克/文字上方直接绘制新标注，修复小椭圆命中、非整数 DPI 属性保真、边缘文字框内收、双击工具栏按钮和长提示条截断问题。
  - GIF 裁剪导出保留抖动设置并采用差分区域编码，修复单帧循环与休眠/拖动后的播放时钟快进，录制浮条与预览按钮统一为按下并松开匹配触发。
  - 贴图视图变换增加异常回滚保护，键盘菜单键居中弹出，折叠态翻转自动展开并消除 `Alt+H`/`Alt+V` 提示音，补齐 GIF/INI/配置长路径兼容。
