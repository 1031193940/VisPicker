# VisPick 0.5.11 Windows 11 便携版

VisPick 是一款采用 MIT 许可证的免费开源截图、参考图和 GIF 录制工具。本版面向 Windows 11 x64，包含自 0.5.3 发布以来的功能更新与修复。

[下载 VisPick-0.5.11.zip](https://github.com/1031193940/VisPicker/releases/download/v0.5.11/VisPick-0.5.11.zip)。解压后运行 `VisPick.exe`，包内另附 32 位构建 `VisPick-x86.exe`，无需安装。

## 本次更新

- 仅保留启动通知。复制、保存、配置重载、重复启动及运行错误不再弹出提示，截图复制浮层已移除。GIF 预览错误显示在状态栏，主动打开的帮助、关于、保存对话框和放弃未保存内容的确认保留。
- 参考图默认固定在创建它的 Windows 虚拟桌面。右键托盘 →「参考图」→「参考图跨桌面」可开启跨桌面显示，设置立即生效并保存。其他桌面上的参考图不再参与当前桌面的吸附。
- 截图与贴图统一使用 `Ctrl+1`。选区工具条提供复制、保存、贴图图标，取消默认 `Ctrl+3`。截图和 GIF 的按钮均使用图标，悬停可查看操作说明。
- GIF 可选择本次录制帧率，最长录制五分钟；预览支持播放、暂停、拖动进度条和复制完整动画到剪贴板。修复预览闪烁，大范围录制超过内存预算时自动按比例降低输出分辨率，保留整个选区。
- Windows 暂时拒绝自动激活选区时，可直接拖动鼠标完成选择。热键被其他程序占用后会自动重试，释放后即可使用。
- 工程新增产品效果图和 30 秒宣传视频。演示素材基于 0.5.9，使用合成示例画面。 [查看效果图](https://github.com/1031193940/VisPicker/blob/v0.5.11/README.md#产品演示) · [观看宣传视频](https://github.com/1031193940/VisPicker/blob/v0.5.11/docs/media/vispick-promo.mp4)

## 开始使用与升级

1. 升级前保存需要保留的参考图和 GIF，再从托盘退出旧版。参考图及回收站只保留在本次运行中。
2. 将便携包解压到可写目录。若要保留已有设置，请在首次启动新版前，把原来的 `VisPick.ini` 复制到新版 exe 所在目录。旧配置位置可在托盘「关于」中查看。
3. 双击 `VisPick.exe`，程序显示启动提醒并常驻托盘。没有配置文件时会生成默认配置；目录不可写时使用 `%APPDATA%\VisPick\VisPick.ini`。编辑配置并保存后自动生效。

| 操作 | 快捷键与流程 |
|---|---|
| 截图和标注 | `Ctrl+1`，拖出选区或单击窗口。按需添加矩形、箭头、画笔、文字等标注。 |
| 复制截图 | 点蓝底对勾，或按 `Enter`、双击选区。 |
| 保存截图 | 点软盘图标或按 `Ctrl+S`，选择 PNG、JPG 或 BMP 文件。 |
| 创建参考图 | 点图钉图标或按 `Ctrl+T`。滚轮缩放，`Ctrl+滚轮` 调整透明度。 |
| 录制 GIF | `Ctrl+2` → 选区 → 选择帧率 → 点圆点开始。再次按 `Ctrl+2` 或点方块停止。 |
| GIF 预览 | 拖动进度条定位，空格暂停或继续；双页图标或 `Ctrl+C` 复制动画，软盘或 `Ctrl+S` 保存。 |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Y`，工具条不再显示这两个按钮。 |

旧配置中的 `[Hotkeys] Pin` 和 `[Gif] MaxSeconds` 会被忽略，其他有效设置保留。`[Pin] AcrossDesktops` 默认 `false`。GIF 复制后的粘贴效果取决于目标应用是否接受 GIF 数据或文件；超过 64 MiB 的录制以文件形式提供。

配置及热键问题可在托盘「关于」查看，其他运行诊断可通过 `[General] Log=true` 启用日志。更多操作见 [使用说明](https://github.com/1031193940/VisPicker/blob/v0.5.11/README.md#使用)。

## 已验证范围与待验证项目

- 0.5.11 的 x64、x86 Release 构建、MSVC 静态分析和系统 DLL 导入检查通过，各通过 306 项单元测试。两种架构的控制台、文件、管道和无控制台输出回归通过。
- 本轮开发中，x64 的图片剪贴板与 GIF 动画复制回归曾完整通过。最终双架构复测受环境限制未完成，独立原生探针确认私有窗口站的剪贴板访问返回 `ERROR_ACCESS_DENIED`。这部分不记为最终复测通过。
- 0.5.10 已完成双架构参考图回归，覆盖虚拟桌面归属、跨桌面开关、隐藏与恢复、图像像素和窗口资源释放。
- Windows 7、Windows 8.1、Windows 10、Windows 11 ARM64，以及干净系统兼容性仍待实机验证。静态导入检查和 Windows 11 上运行 x86 不能替代这些验证。
- 不同硬件的多屏、混合 DPI、全屏 GIF 长录制性能，真实中文输入法组合输入，以及第三方应用的 GIF 粘贴和播放仍需继续验证。

八小时稳定性测试保留为可选诊断，不作为发布限制。本次发布沿用已有构建和验证记录，没有重新运行长期测试。 [完整更新日志](https://github.com/1031193940/VisPicker/blob/v0.5.11/CHANGELOG.md)
