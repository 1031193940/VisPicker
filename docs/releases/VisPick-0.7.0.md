## 本版更新

- **标注可再次编辑**。点击标注后可拖动移动，矩形和椭圆可调整尺寸，箭头可调整端点。移动、缩放、修改属性和删除均支持撤销与重做。
- **文字可重新输入**。双击文字或选中后按 Enter，可在原有内容上继续编辑。
- **属性栏随标注切换**。形状显示颜色和线宽，文字显示颜色和字号，马赛克显示块大小。编辑多行文字时，工具栏会避开输入框。
