# VisPick 0.6.0

发布日期：2026-11-10。面向 Windows 11 x64，Release 仅提供一个独立的 `VisPick_0.6.0.exe`，不附带 ZIP、配置模板或其它文件。x86 继续保留源码构建和 CI 验证；Win7/Win10 兼容性仍待实际验证。

[下载 VisPick_0.6.0.exe](https://github.com/1031193940/VisPicker/releases/download/v0.6.0/VisPick_0.6.0.exe)

文件大小：866,816 bytes。SHA256：`dacf215abea86782810edcca7216eb9ffb4179050604e9db5acecd7aea3de109`。

## 本版变化

- 恢复错误通知，成功操作保持静默；浮层窗口异常时取消选区并释放资源。
- 增加当前显示器/窗口候选/尺寸调整快捷键、HEX/RGB 颜色复制、随 DPI 缩放的放大镜和抗锯齿图标。
- GIF 录制支持暂停/继续，预览支持首尾裁剪；保存和复制均输出所选片段。
- 截图先提供原始像素格式，再后台补充 PNG，并保护后续复制的内容。
- 完善配置原子写入、工具链选择和双架构 CI。默认热键继续使用 Ctrl+1 截图、Ctrl+2 GIF。

## 使用

下载后双击 `VisPick_0.6.0.exe`。程序无需安装，启动后驻留系统托盘，右键图标打开菜单。同一用户会话只运行一个实例。

升级前先保存需要保留的参考图和 GIF，从托盘退出旧版，将新 exe 放到原目录并运行，保留原有 `VisPick.ini` 即可继续使用自定义设置。若曾启用开机自启，请在新版托盘菜单中关闭再开启一次，以更新启动路径。程序不会自动保存退出前的参考图。

| 操作 | 入口 |
|---|---|
| 截图 | Ctrl+1，拖选区域或单击识别到的窗口 |
| 复制截图 | 蓝底对勾、Enter、双击选区或 Ctrl+C |
| 保存截图 | 软盘图标或 Ctrl+S，选择 PNG/JPG/BMP 和保存位置 |
| 创建参考图 | 图钉图标或 Ctrl+T |
| 标注 | R 矩形、E 椭圆、A 箭头、P 画笔、T 文字、M 马赛克 |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Y |
| 当前显示器 | Ctrl+A 选择鼠标所在显示器 |
| 窗口候选 | Tab / Shift+Tab 在冻结的顶层窗口候选间切换 |
| 选区微调 | 方向键移动；Ctrl+方向键调整右/下边界；加 Shift 变为 10 个物理像素 |
| 取色 | C 复制鼠标处冻结画面的 `#RRGGBB`；Shift+C 复制 `RGB(R, G, B)` |
| 取消选区 | Esc、叉号；未取得键盘焦点时也可右键取消 |

文字编辑框活跃时，文字的选择和输入快捷键优先。放大镜保持 15×15 个取样格，单格随界面 DPI 缩放。按钮显示图标，悬停显示操作名称和快捷键。

截图会立即提供 DIBV5（含透明度）和 DIB（白底兼容副本），后台再补充 PNG。若用户已复制其他内容，旧截图的 PNG 会被丢弃。PNG 尚未就绪或目标应用正在占用剪贴板时，可以先粘贴 DIB；目标应用的格式支持决定最终效果。

## GIF

Ctrl+2 打开选区，选择本次帧率后点录制图标或按 Enter。默认帧率由 `[Gif] Fps` 配置。录制最多五分钟，暂停时间不计入录制时长。

- 工具条上的双竖线暂停，三角形继续；锁屏或会话暂停不会解除用户主动暂停。
- 点方块或再按 Ctrl+2 停止，打开预览。
- 点击或拖动进度条定位，空格暂停/播放。
- 定位后点“从当前帧开始”图标或按 `[`，设置保留片段的起点。
- 点“在当前帧结束”图标或按 `]`，设置终点。保留当前显示帧的完整延时。
- 重置图标或 Ctrl+R 恢复完整录制。黄色标记显示范围，播放时循环选中片段。
- 双页图标或 Ctrl+C 复制当前片段；软盘或 Ctrl+S 保存当前片段。

未裁剪的导出保留原始 GIF 文件数据；裁剪需要重新合成和编码，颜色可能再次量化，文件可能变大。保存或复制失败后原录制仍保留，可以调整后重试。

GIF 剪贴板同时提供动画数据和文件引用（超过 64 MiB 时提供文件引用）。目标应用必须支持 GIF 数据或文件，部分应用只会显示静态图。临时文件在 `%TEMP%\VisPick`，启动时清理一天前本程序遗留的临时文件。

大选区超过当前架构内存预算时自动降低输出分辨率，保留完整选区。预览显示实际尺寸。旧系统全屏录制可能隐藏工具条，此时使用 GIF 热键停止。

## 参考图

拖动或方向键移动，滚轮缩放，Ctrl+滚轮调透明度，双击收缩/恢复，R 旋转，Alt+H/V 镜像。Ctrl+C/X/V/S 分别复制、剪切、剪贴板新贴图和保存。Esc/Q 关闭入回收站，Ctrl+Z 恢复最近关闭。

参考图默认留在创建时的 Windows 虚拟桌面。托盘 → 参考图 →“参考图跨桌面”可切换，立即应用并保存为 `[Pin] AcrossDesktops`。退出程序后参考图和回收站不保留。

## 配置与通知

Release 不附带默认配置，首次运行时程序自行生成 `VisPick.ini`；exe 目录不可写时使用 `%APPDATA%\VisPick\VisPick.ini`。编辑后自动重载，无效项保留上次有效值。需要查阅完整配置时见仓库中的 [默认配置模板](https://github.com/1031193940/VisPicker/blob/v0.6.0/res/default.ini)。

默认保留启动提醒，恢复操作失败提示，成功操作保持静默。重复启动会重放运行提醒；启动时汇总快捷键冲突，托盘“关于”可查看详情。

```ini
[General]
Notify=errors
```

`errors` 是默认值；`all` 也显示已有的信息通知；`none` 只保留启动提醒。GIF 保存/复制错误仍在预览状态栏显示。Windows 勿扰或系统通知设置可能拦截托盘气泡。

Ctrl+1/Ctrl+2 保持原默认值，托盘显示当前配置的组合。在 `[Hotkeys]` 修改或留空可禁用。旧 Ctrl+3 的 `Pin` 配置继续忽略。`[Advanced] CaptureLayeredGif` 是规范写法，旧的 `capture_layered_gif` 仍兼容。

默认关闭日志和开机自启。需要诊断时使用 `--perf` 或 `[General] Log=true`，在“关于”查看配置与热键状态。程序没有网络上传逻辑。

## 未通过的验收项

| 项目 | 结果与边界 |
|---|---|
| 前景拒绝夹具 / 跨进程生命周期 | 前景锁定返回 `ERROR_ACCESS_DENIED (5)`，部分选区激活前提失败。0.5.11 对照也出现激活失败，尚不能确定为本轮产品回归；此项未验收通过。 |
| x86 完整选区流程 | 双屏像素、工具条及 GIF 帧率检查通过，后续前景切换中断；整体未通过。 |
| 双 4K 全桌面初始化 | 分配及采集为 208.13 ms，超过原 150 ms 门槛；像素与资源回收正确。 |
| 旧浮层原型最大重绘 | 平均 2.85 ms，最大 32.73 ms，超过 16 ms 门槛；这是旧原型，不能当作当前产品 Overlay 的性能结果。 |
| P0 GIF 正确性原型 | 第 54 tick 图样失配；首次差异命中 `VirtualDesktopHotkeySwitcher`，存在切桌面/覆盖干扰线索，根因未确认。 |
| P0 GIF pipeline 原型 | 捕获 300 帧，拒绝 1 个未知/撕裂/被覆盖帧，未达到零拒绝帧要求；其余 299 帧解码零差异、时长误差 0.031%，无调度/队列跳帧。 |

1080p CAPTUREBLT P95 为 17.80 ms，超过设计中的 15 ms 后端调研触发线。当前采集仍是 BitBlt，WGC/DXGI 后端与 HDR 色调映射未加入本版。产品 GIF 功能回归通过不等于上述原型性能和正确性门槛全部通过。

## 尚未验收及使用限制

- Win7、Win10、干净系统、混合 DPI 多屏和 HDR。Win11 上运行 x86 与导入白名单均不能替代目标系统实测。
- 前景权限受控的完整生命周期、第三方软件粘贴、真实中文输入法组合输入。
- 只读目录保存失败、热键冲突、录制中磁盘写满三种场景下的系统通知实际呈现。
- 本轮未跑十分钟空闲测量；八小时浸泡仍不是发布门槛。
- exe 未签名，Windows 可能显示下载或运行信誉提示。
