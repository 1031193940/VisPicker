# VisPick 0.6.0 Windows 便携版

本文件描述 0.6.0 的使用方式。当前为本地开发构建，尚未发布到 GitHub；公开下载仍为 0.5.11。

## 使用

解压整个目录。Windows 11 x64 使用 `VisPick.exe`；`VisPick-x86.exe` 是 32 位构建。程序无需安装，启动后驻留系统托盘，右键图标打开菜单。同一用户会话只运行一个实例。

升级前先保存需要保留的参考图和 GIF，从托盘退出旧版，再启动新版。将旧目录的 `VisPick.ini` 复制到新目录即可保留配置。程序不会自动保存退出前的参考图。

| 操作 | 入口 |
|---|---|
| 截图 | Ctrl+1，拖选区域或单击识别到的窗口 |
| 复制截图 | 蓝底对勾、Enter、双击选区或 Ctrl+C |
| 保存截图 | 软盘图标或 Ctrl+S，选择 PNG/JPG/BMP 和保存位置 |
| 创建参考图 | 图钉图标或 Ctrl+T |
| 标注 | R 矩形、E 椭圆、A 箭头、P 画笔、T 文字、M 马赛克 |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Y |
| 当前显示器 | Ctrl+A 选择鼠标所在显示器 |
| 窗口候选 | Tab / Shift+Tab 在冻结的顶层窗口候选间切换 |
| 选区微调 | 方向键移动；Ctrl+方向键调整右/下边界；加 Shift 变为 10 个物理像素 |
| 取色 | C 复制鼠标处冻结画面的 `#RRGGBB`；Shift+C 复制 `RGB(R, G, B)` |
| 取消选区 | Esc、叉号；未取得键盘焦点时也可右键取消 |

文字编辑框活跃时，文字的选择和输入快捷键优先。放大镜保持 15×15 个取样格，单格随界面 DPI 缩放。按钮显示图标，悬停显示操作名称和快捷键。

截图会立即提供 DIBV5（含透明度）和 DIB（白底兼容副本），后台再补充 PNG。若用户已复制其他内容，旧截图的 PNG 会被丢弃。PNG 尚未就绪或目标应用正在占用剪贴板时，可以先粘贴 DIB；目标应用的格式支持决定最终效果。

## GIF

Ctrl+2 打开选区，选择本次帧率后点录制图标或按 Enter。默认帧率由 `[Gif] Fps` 配置。录制最多五分钟，暂停时间不计入录制时长。

- 工具条上的双竖线暂停，三角形继续；锁屏或会话暂停不会解除用户主动暂停。
- 点方块或再按 Ctrl+2 停止，打开预览。
- 点击或拖动进度条定位，空格暂停/播放。
- 定位后点“从当前帧开始”图标或按 `[`，设置保留片段的起点。
- 点“在当前帧结束”图标或按 `]`，设置终点。保留当前显示帧的完整延时。
- 重置图标或 Ctrl+R 恢复完整录制。黄色标记显示范围，播放时循环选中片段。
- 双页图标或 Ctrl+C 复制当前片段；软盘或 Ctrl+S 保存当前片段。

未裁剪的导出保留原始 GIF 文件数据；裁剪需要重新合成和编码，颜色可能再次量化，文件可能变大。保存或复制失败后原录制仍保留，可以调整后重试。

GIF 剪贴板同时提供动画数据和文件引用（超过 64 MiB 时提供文件引用）。目标应用必须支持 GIF 数据或文件，部分应用只会显示静态图。临时文件在 `%TEMP%\VisPick`，启动时清理一天前本程序遗留的临时文件。

大选区超过当前架构内存预算时自动降低输出分辨率，保留完整选区。预览显示实际尺寸。旧系统全屏录制可能隐藏工具条，此时使用 GIF 热键停止。

## 参考图

拖动或方向键移动，滚轮缩放，Ctrl+滚轮调透明度，双击收缩/恢复，R 旋转，Alt+H/V 镜像。Ctrl+C/X/V/S 分别复制、剪切、剪贴板新贴图和保存。Esc/Q 关闭入回收站，Ctrl+Z 恢复最近关闭。

参考图默认留在创建时的 Windows 虚拟桌面。托盘 → 参考图 →“参考图跨桌面”可切换，立即应用并保存为 `[Pin] AcrossDesktops`。退出程序后参考图和回收站不保留。

## 配置与通知

首次运行生成 `VisPick.ini`；exe 目录不可写时使用 `%APPDATA%\VisPick\VisPick.ini`。编辑后自动重载，无效项保留上次有效值。包内 `res/default.ini` 是完整默认模板。

默认保留启动提醒，恢复操作失败提示，成功操作保持静默。重复启动会重放运行提醒；启动时汇总快捷键冲突，托盘“关于”可查看详情。

```ini
[General]
Notify=errors
```

`errors` 是默认值；`all` 也显示已有的信息通知；`none` 只保留启动提醒。GIF 保存/复制错误仍在预览状态栏显示。Windows 勿扰或系统通知设置可能拦截托盘气泡。

Ctrl+1/Ctrl+2 保持原默认值，托盘显示当前配置的组合。在 `[Hotkeys]` 修改或留空可禁用。旧 Ctrl+3 的 `Pin` 配置继续忽略。`[Advanced] CaptureLayeredGif` 是规范写法，旧的 `capture_layered_gif` 仍兼容。

默认关闭日志和开机自启。需要诊断时使用 `--perf` 或 `[General] Log=true`，在“关于”查看配置与热键状态。程序没有网络上传逻辑。

## 验证范围与限制

本轮双架构 Release、静态分析、导入/体积检查及各 321 项单元测试通过。剪贴板、标注、参考图、GIF 暂停/裁剪、常驻框架和控制台回归通过。详情在仓库的 `docs/reviews/Implementation-Optimization-2026-11-10.md`。

本地双 4K、175%、60 Hz 的像素与资源检查通过，但整桌面初始化和原型最大重绘仍超过原性能目标；完整前景/生命周期测试受到桌面权限拒绝，未记为通过。x64 独立选区流程通过，x86 选区流程在前景切换处中断。

- 继续保留 x64/x86；Win7、Win10、干净系统、混合 DPI 多屏和 HDR 仍待实际验证。
- 当前采集仍是 BitBlt。WGC/DXGI 后端和 HDR 色调映射未加入本版。
- 八小时浸泡不是发布门槛；未恢复该限制。
- 第三方软件粘贴、中文输入法组合输入和系统通知实际呈现仍需对应环境验收。
- exe 未签名，Windows 可能显示下载或运行信誉提示。
