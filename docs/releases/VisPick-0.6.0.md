# VisPick 0.6.0

2026-11-10 · Windows 11 x64 · [下载 VisPick_0.6.0.exe](https://github.com/1031193940/VisPicker/releases/download/v0.6.0/VisPick_0.6.0.exe) · [使用说明](https://github.com/1031193940/VisPicker#readme)

## 本版更新

- **GIF 暂停与裁剪**：录制中可暂停、继续；预览中设置片段起止位置，保存或复制选中的片段。
- **键盘选区**：Ctrl+A 选择当前显示器，Tab / Shift+Tab 切换窗口候选，Ctrl+方向键调整选区尺寸。
- **快捷取色**：C 复制 HEX 色值，Shift+C 复制 RGB 色值。
- **界面显示**：放大镜随 DPI 缩放，工具条图标增加抗锯齿。
- **截图复制**：先提供图像，再后台补充 PNG，避免旧截图覆盖之后复制的内容。
- **通知与可靠性**：恢复错误提示，成功操作保持静默；完善配置保存和选区异常清理。

## 已验证范围

- Windows 11 双 4K、175% DPI 环境下，截图输出、标注、参考图及产品 GIF 录制／暂停／裁剪回归通过，x64 完整选区流程通过。
- x64/x86 构建、静态分析及各 321 项单元测试通过；x86 为开发构建，运行于上述 64 位系统。

## 未通过与待验收

- **未通过**：部分前景激活、跨进程生命周期及 x86 完整选区测试，原因仍待确认。
- **性能未达标**：双 4K 全桌面初始化、旧浮层原型最大重绘；后者不是当前产品浮层的测量结果。
- **原型正确性未通过**：P0 GIF 图样失配，流水线 300 帧中拒绝 1 帧；与上述产品 GIF 功能回归分开记录。
- **待验收**：Win7/Win10、干净系统、混合 DPI/HDR、第三方粘贴、真实中文输入法和系统错误通知；本轮未测十分钟空闲。
