# VisPick 0.5.1-candidate 评审修正记录

本轮对照 [P1–P6 评审](P1-P6-code-review-2026-11-06.md) 修复可确认的缺陷，并保留原设计中的验收阈值。`0.5.0-candidate` 的历史报告保留原数据。

| 编号 | 处理 |
|---|---|
| H-01、L-21、D-02 | 移除录制全局 Esc 注册。较长录制点取消或录制中请求退出时，先完成可保存的 GIF，再让用户决定。旧系统全屏用 GIF 热键停止。 |
| H-02、V-09 | 浮层检查真实前台与焦点，激活失败时撤销全屏窗口。Alt+Tab 或失去激活时取消，原生文字控件和保存对话框属于同一会话。测试夹具只授权自有窗口和子进程，生产程序遵守系统前台限制。 |
| H-03、M-01、D-03 | 默认 `SRCCOPY`。`[Advanced] capture_layered_gif=true` 启用 `CAPTUREBLT`，日志和 E2E 记录实际路径。两种路径的光标表现、Aero 和物理性能待测。 |
| M-02、M-03、V-13 | 生产 GIF 帧至少 20 ms，合并过密变化，尾帧用同一时序规则。WIC 往返覆盖 1 色和 255 色透明差分帧。Chromium 对 10 ms 及以下帧有延时修正。见 [Chromium 实现](https://chromium.googlesource.com/chromium/src/+/HEAD/third_party/blink/renderer/platform/graphics/deferred_image_decoder.cc)。 |
| M-04、L-14、L-18、L-19 | 单次 BitBlt 或光标失败分别计数。连续采集失败时停止并保留已录帧。优先编码最早序号，计入向量增长峰值，并补充完成通知的容错。 |
| M-05、L-15、L-16、V-11、V-12 | 后台解码预取、后台提交文件。失败保留预览和源临时文件供重试。构造失败清理临时文件，系统注销等待已接受的保存。覆盖保存与长路径使用共享文件提交逻辑。 |
| M-06、L-25、L-26 | 浮层从三张整屏 DIB 减到两张。标注缓存限制 16 MiB，超限分块绘制。以 7680×2160 有标注画布估算，这些缓冲约从 253 MiB 降至最多 143 MiB。GDI+ 按进程延迟初始化。剪贴板 PNG 直接交付 WIC 的 HGLOBAL，DIB 直接写入交付缓冲。 |
| M-07、L-30、V-14 | IME 完成后提交文字，按 EDIT 会话代数识别过期消息，异常后销毁控件。新增模拟组合结果和旧消息测试。真实输入法组合和候选窗待测。 |
| M-08、M-09、M-15、D-01、D-05 | 选区操作期间固定 UI 缩放，防止跨屏拖动时手柄突变。有标注时保护既有选区。三种模式切换共享冻结帧、选区和标注历史。 |
| M-10、M-18、V-15 | 覆盖时使用 `ReplaceFileW` 保留 DACL、隐藏属性和备用流，并保留回退文件。验证长 Unicode 路径和只读目标。PNG 无效时按剪贴板序列号安全回落到 DIB。V5 支持显式 alpha 和非零 alpha 兼容路径。 |
| M-11、M-17、L-01、L-06～L-08、V-16 | 空配置拒绝并延后重试，缺失项保留已有值。无 BOM 时才尝试系统代码页，支持全角空格。未改变的热键保持注册。常用裸键提示全局占用，贴图不透明度下限与交互一致。 |
| M-12、M-13、M-20、L-03～L-05 | 单张贴图更新失败不会阻断其余贴图或热键。激活只更新装饰和透明度。4K 保持原像素，预算超限明确拒绝，增加源图、显示缓存和回收站合计上限。生产显示器枚举分离诊断探测。回收恢复失败保留原图。 |
| M-14 | 默认配置路径不写进 Run 命令。修复仅在同名旧程序确实不存在时发生，并保留既有显式配置参数。 |
| M-16、L-11、B-07、V-17 | Release PDB 按 exe SHA-256 归档。支持未处理 SEH、terminate、abort、无效参数和纯虚调用。去掉故障线程的模态窗口，后到故障线程给正在写入的转储留出时间。当前仍用进程内按需 DbgHelp，损坏进程的转储属于尽力而为。见 [Microsoft 的转储说明](https://learn.microsoft.com/windows/win32/api/minidumpapiset/nf-minidumpapiset-minidumpwritedump)。 |
| M-19 | 四个系统依赖改为延迟加载，使用系统目录绝对路径。Win7 未安装搜索标志更新时使用绝对路径回退。白名单校验普通与延迟导入，并阻止四个依赖回到静态表。旧系统运行时仍需验证。 |
| L-02、L-09、L-10、L-12 | 模态深度按计数维护。拦截 Windows 保留名并支持双花括号。IPC 接收端拒绝相对贴图路径，启动转发等待仍有上限。生产录制原本已关闭跨帧调色板复用。 |
| L-13、L-17、L-22～L-24、L-27～L-29 | 提高抖动缓存键的精度，录制按钮避免依赖特殊字形，保存对话框有可见 owner。过滤穿透浮窗，拖动中忽略方向微调，校验 DPI 切换后的窗口边界，超宽坐标提前拦截。 |
| B-01～B-06、B-08、D-10 | CMake 生成版本信息和 manifest。两架构构建记录输入指纹与 exe 哈希，打包时交叉校验。便携包只保留程序、快速说明、配置模板和更新日志。设计更新至 v0.3，日志位置和录制退出行为已同步。 |
