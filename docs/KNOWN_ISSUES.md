# 已知限制与待验收项目

0.5.3 便携版面向 Windows 11 x64。功能回归在该系统的单屏 RDP 会话完成，同时覆盖了 32 位构建。完整兼容矩阵仍待验证。 [私有提交排查与复测](reports/P6-memory-2026-11-06.md) · [验收清单](P6_CHECKLIST.md)

| 项目 | 当前边界与下一步 |
|---|---|
| Win7 / Win10 / 干净系统 | 已做静态 CRT 和 Win7 导入审查；尚需目标系统实际启动、E2E 和手工操作。当前 Win11 上运行 x86 不能替代 Win10/Win7 x86。 |
| 物理显示性能 | 当前远程显示为 2560×1440、125% DPI、32 Hz；不作为双 4K、混合 DPI、笔画耗时或 30 fps 丢帧率验收。保留数值，待物理设备复测后决定是否需要 DXGI。 |
| 原生中文输入 | 原生 EDIT 提交前后像素比较已覆盖中文、多行、Tab 和换行；实际微软拼音、搜狗组合输入仍需手工验证。 |
| 跨应用粘贴与播放 | 0.5.3 的短 GIF 在 Chrome、Edge、Firefox 和 Windows 照片中通过合成抽样。第三方应用的粘贴、微信与 QQ 播放以及其他手工图样仍待验证。 |
| GIF 照片/视频质量 | 精确调色板内图像可无损；超过 255 色需要量化。可启用 Dither 降低部分渐变色带，但会增加噪点/体积；视频调色板变化仍需实际观感评审。 |
| 长时间浸泡诊断 | 原 AC6-3 已退出发布验收。0.5.3 候选构建完成 720.047 秒复测，私有提交峰值 +2.18%。八小时试跑在 136.497 秒收到 RDP 会话锁定通知并结束。 [复测报告](reports/P6-memory-2026-11-06.md) |
| 系统注销中的未保存 GIF | 普通退出会确认；系统已提交结束会话时不再弹框，已完成预览的 GIF 保留在 `%TEMP%\VisPick`。可在一天内手动取回；下次启动会清理超过一天的程序录制临时文件。 |
| 极大图像与 x86 地址空间 | 解码尺寸、录制槽位和贴图渲染面积有边界以避免无限分配；超出时提示错误。x86 可用地址空间仍受系统和碎片影响。 |
| 旧系统全屏录制 | 录制工具条优先放到区域外。无空间时隐藏，用 GIF 热键停止，再在预览中保存或放弃。 |

所有数值门槛沿用 DESIGN.md。未测试不改写成通过，也不使用降低采样时长或主动裁减工作集的方式取得验收结果。
